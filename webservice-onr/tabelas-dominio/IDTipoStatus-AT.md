# IDTipoStatus — Acompanhamento de Títulos

Código do **tipo de status** do título (filtro em `ListTitulosAT` / `ListStatusAT`, cadastro em `InsertTituloAT` / `InsertStatusAT`).

Fonte: especificação § **3.2.1** (`ListTitulosAT`).

| Valor | Descrição |
|-------|-----------|
| `1` | Título com reingresso |
| `2` | Exame e cálculo cancelado |
| `3` | Título pronto para retirada |
| `4` | Título prenotado |
| `5` | Exame e cálculo concluído |
| `6` | Título registrado |
| `7` | Nota de exigência |
| `8` | Título entregue |
| `9` | Suscitação de dúvida |
| `10` | Dúvida julgada procedente |
| `11` | Dúvida julgada improcedente |
| `12` | Exame e cálculo protocolado |
| `13` | Exame e cálculo pronto para a retirada |
| `-1` | Todos _(filtro em listagens)_ |
