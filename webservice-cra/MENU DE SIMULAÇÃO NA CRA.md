## Menu de Simulacao: Ferramenta para[Testes]

Estimated reading: 2 minutes : 57 views

O menu de Simulacao é uma ferramenta exclusiva do ambiente de testes, projetada para auxiliar os apresentantes durante a fase de homologacao. Com ele, é possivel ter total controle sobre o fluxo de arquivos, sem depender de intervencao externa.

As principais funcionalidades sao:

- cartorio.

- Gerar Retornos: Simula o envio do status final dos titulos (ex: protestado, pago)

- Limpar Dados de Teste: Permite apagar todas as remessas e dados ja enviados para reiniciar o ambiente.

## Como Simular a Confirmacao de uma Remessa

Siga os passos abaixo para gerar o arquivo de confirmacao de uma remessa que você

enviou.

## Acesse o Menu de Confirmacao

No menu lateral, navegue até Simulacao > Confirmacao

## Localize a Remessa

A tela exibira uma lista de todas as remessas que estao pendentes de confirmacao. Para buscar: Se desejar encontrar uma remessa especifica, utilize o filtro "Data Remessa" Gere a Confirmacao

Vocé tem duas opções: Confirmar uma remessa individual: Localize a remessa na lista e

processar todas as pendéncias de uma so vez, utilize o botao "Gerar Todas".

## Acesse o Menu de Retorno

No menu lateral, navegue até Simulacao > Retorno. Localize a Remessa

A tela exibira uma lista de todas as remessas que estao pendentes de retorno. Para buscar: Se desejar encontrar uma remessa especifica, utilize o filtro "Data Confirmacao" Gere o Retorno

Vocée tem duas opções: Retornar uma remessa individual: Localize a remessa na lista e

clique no botao verde “Gerar Retorno" ao lado dela. Retornar todas as remessas: Para

processar todas as pendéncias de uma so vez, utilize o botao "Gerar Todas".
